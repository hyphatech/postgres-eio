You need **opam**, OCaml's package manager, **OCaml 5.5 or later**, and a
Postgres server to connect to. postgres-eio brings **dune**, the build tool,
with it.

## 1. Install opam

<Tabs>
<TabItem label="macOS">

```sh
brew install opam
```

</TabItem>
<TabItem label="Linux">

```sh
bash -c "sh <(curl -fsSL https://opam.ocaml.org/install.sh)"
```

</TabItem>
<TabItem label="Windows">

```powershell
winget install Git.Git OCaml.opam
```

postgres-eio should work on Windows, but it is not tested there. If
something fails, [WSL](https://learn.microsoft.com/windows/wsl/install) gives
you a Linux to follow the Linux steps in.

</TabItem>
</Tabs>

## 2. Set up OCaml

```sh
opam init
```

Answer yes when it offers to set up your shell. This installs the latest
OCaml, which takes a few minutes. Then let this terminal see it -- a new
terminal does by itself:

<Tabs>
<TabItem label="macOS and Linux">

```sh
eval $(opam env)
```

</TabItem>
<TabItem label="Windows">

```powershell
(& opam env) -split '\r?\n' | ForEach-Object { Invoke-Expression $_ }
```

</TabItem>
</Tabs>

<details>
<summary>Already had opam?</summary>

Check `ocaml -version`. If it is older than 5.5, make a switch -- an
environment of its own -- with the latest OCaml:

```sh
opam switch create postgres-eio ocaml-base-compiler
eval $(opam env)
```

</details>

## 3. Install postgres-eio

```sh
opam repo add hypha https://github.com/hyphatech/opam-repository.git
opam install postgres-eio
```

This installs the driver and everything it needs. A program runs it inside
Eio's event loop, which `eio_main` starts, so install that beside it:

```sh
opam install eio_main
```

A program names both in its `dune` file:

```lisp
(libraries postgres-eio eio_main)
```

## Check it worked

```console
$ ocaml -version
The OCaml toplevel, version 5.5.1

$ opam list postgres-eio
```

It lists `postgres-eio` with a version, not `--`, under *Installed*.

## Your editor

For completion, types on hover and errors as you type, install the language
server, then the **OCaml Platform** extension in VS Code -- or the OCaml
support of your editor:

```sh
opam install ocaml-lsp-server
```

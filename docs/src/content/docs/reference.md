Every module's interface, generated by odoc from its `.mli`, where each
function says what it does, what it refuses and what it defaults to.

## The package

| Package | Libraries | What it is |
|---|---|---|
| `postgres-eio` | `postgres-eio` | The driver: connections, the pool, connection strings, and cell values |

A `dune` file names the library as it is installed (`postgres-eio`); OCaml
code names it as a module (`Postgres_eio`).

## postgres-eio

- [`Postgres_eio`](/postgres-eio/reference/postgres-eio/Postgres_eio/index.html)
  -- connections: connecting, statements, COPY, the session, and
  notifications. Within it,
  [`Pipeline`](/postgres-eio/reference/postgres-eio/Postgres_eio/Pipeline/index.html),
  [`Listener`](/postgres-eio/reference/postgres-eio/Postgres_eio/Listener/index.html)
  and [`Resolver`](/postgres-eio/reference/postgres-eio/Postgres_eio/Resolver/index.html).
- [`Pool`](/postgres-eio/reference/postgres-eio/Postgres_eio/Pool/index.html)
  -- a fixed-size pool that lends every connection in a clean state.
- [`Conninfo`](/postgres-eio/reference/postgres-eio/Postgres_eio/Conninfo/index.html)
  -- connection strings, the `PG*` variables and `.pgpass`.
- [`Server_error`](/postgres-eio/reference/postgres-eio/Postgres_eio/Server_error/index.html)
  -- a server's error, every field of it.
- [`Tag`](/postgres-eio/reference/postgres-eio/Postgres_eio/Tag/index.html)
  -- a statement's command tag.

The lower layers do no IO and can be used alone:

- [`Text`](/postgres-eio/reference/postgres-eio/Postgres_eio/Text/index.html)
  -- values written as Postgres reads them, and read as it writes them.
- [`Value`](/postgres-eio/reference/postgres-eio/Postgres_eio/Value/index.html)
  -- cells decoded alike from text and binary results.
- [`Column`](/postgres-eio/reference/postgres-eio/Postgres_eio/Column/index.html)
  -- a result's column, as the server describes it.
- [`Oid`](/postgres-eio/reference/postgres-eio/Postgres_eio/Oid/index.html)
  -- the identifier of a type, or another row of a system catalogue.
- [`Interval`](/postgres-eio/reference/postgres-eio/Postgres_eio/Interval/index.html)
  -- an `interval`, its months, days and microseconds kept apart.
